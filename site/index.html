Study guides that are not allowed to make things up.

An agent pipeline built on Claude Code, Python and LaTeX. It turns a course's lecture notes and past exam papers into a print-ready guide, and every stage has to pass a gate before the next one runs.

Why it exists

Version 1 wrote a convincing 2024 paper. None of it was real.

The first version was one long prompt. Its guides looked finished, and its "2024 past paper" chapter read like the real thing. An audit against the scanned paper found that 0 of its 13 questions appeared in the actual exam.

A student who trusts a made-up paper studies the wrong things. So version 2 was rebuilt around one rule: a stage counts as done only when a check that the writer cannot influence says so.

  • Past-paper questions come only from a bank transcribed from page images.
  • Each printed question carries a cropped image of the original, a "receipt".
  • Every numerical answer has a Python check that runs on each build.

    Planning

    What to study when there are only a few hours left.

    The planner turns the verified bank into a marks model per topic, simulates papers under the exam's choice rules, and picks the set of question ideas that covers the most expected marks for a 3, 6 or 12-hour budget. Those plans set the study order of the whole guide.

      What the numbers do not show yet

      The planner's 6-hour plan covered 0.41 of the marks on held-out papers, against 0.36 for picking ideas at random. With four folds that gap is not conclusive, and per-idea probabilities are no better than a flat base rate.

      So the guides print likelihood as a band or "rough estimate", never as a precise chance, and the wording is enforced in the planner's output.

      One course had no past papers at all. The pipeline runs it in a labelled weak-input mode instead of pretending.

      Engineering practice

      Built like software, not like a prompt.

      Test first, journaled

      Each of the 34 changes started with a failing test and is recorded with its scores in an append-only journal. Reverts are recorded too.

      Regression suite on synthetic fixtures

      28 test files (about 5,700 lines) cover 11,600 lines of tools. Every bug found on real data became a test.

      Resumable by design

      A ledger records each finished step, so a run that stops at a usage limit continues where it left off.

      Parallel agents that cannot collide

      Writers own named files and compile only their own pieces against one shared LaTeX style.

      Model tiering by evidence

      Cheap models run checks, mid-tier models write under gates, and the top model keeps the judgment calls.

      Local CI

      The whole gate runs on a laptop with one command. Hosted CI is manual and only smoke-tests a fresh clone.

      Future work

      What comes next.

      1. Next

        Score the planner after each real exam

        Bank the new paper, run the post-exam scorer, and publish predicted against actual coverage per course. This is the data the planner needs to be calibrated.

      2. Next

        A convention-consistency checker

        Most real review findings were one fact stated two ways. Decide conventions before writing and check every boxed answer against them automatically.

      3. Next

        A fully public sample guide

        Run the pipeline on openly licensed course material so a complete guide, with its web edition, can be published without anyone's exam papers.

      4. Later

        A planner that beats the base rate

        Pool evidence across courses with a hierarchical model and report calibration, not only coverage.

      5. Later

        Cheaper orchestration

        The orchestrating session is now the largest cost line. Batch its turns and move phases into single commands.

      6. Later

        Other universities and other agent runners

        The pipeline is plain files. Package the subject template and test it under a second coding agent.

      7. Later

        Close the loop with readers

        An error-report form whose confirmed reports become regression tests, and spaced repetition in the web edition.
